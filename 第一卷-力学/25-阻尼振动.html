介质吃掉的那部分机械能，什么时候还能用一个力学项来写？

同一个弹簧振子，放在空气里能摆很久，浸到水里几次就看得出幅度在掉。差的不是振幅大一点小一点，而是运动本身还可能换一种走法：有的系统仍旧来回振荡、幅度慢慢变小，有的干脆不再往复，只是缓慢地回到平衡位置。§21 的自由振动方程里没有位置给这种差别，因为它假定了机械能守恒。要让这一类现象回到可计算的范围内，只能先把介质的角色压缩成一个力学项。

介质有自己的运动和内部状态，严格说阻力可以依赖过去发生过的一切，物体受到的力也就不再是此刻坐标与速度的函数。要让方程仍然写成力学方程，需要对介质和运动加条件：介质的耗散过程比振动的每一次往复都快得多，也就是振动频率远小于介质内部耗散过程的频率；同时速度足够小。第一条保证阻力在瞬时速度上就看得到滞后，不必记住历史；第二条允许把阻力按速度的幂次展开。介质静止时物体静止，阻力也就为零，所以展开式里没有常数项，剩下最靠前的就是一次项。

「摆得越来越小」和「不再往复」，怎样从同一个方程里分出来？

恢复力仍然与位移成正比，阻力与速度成正比，方程里每一项都是 x 或它的一次导数乘常数。指数函数的特点是每求一次导数就乘回自己，代进方程后各阶导数会一起转成同一个因子，微分方程随之降成普通的代数方程。这正是下面试探解的用处：不必靠猜，只要看代进去之后剩下什么。

振幅按指数掉下去，能量也按同一个指数掉吗？

图上的包络看起来就是一个指数，很容易顺手把机械能也写成指数。但包络是从位移曲线上看出来的，能量是速度与位移的组合，两者并不必然同步。判断这件事有一个直接办法：先老老实实对真实的机械能求导，看摩擦在每一个时刻拿走了多少，再决定能不能对它作周期平均。

这一步没有用到任何近似：把 E 的定义式对时间求导，代入运动方程消去 ẍ，剩下的就是阻力做的功。结果有两件事可说。一是符号，λ 与 ẋ² 都不为负，所以 Ė 小于或等于零，机械能每个时刻都不增加，它去的地方是介质的内能。二是转折点：速度为零的那一刻，瞬时耗散功率也是零。这一点立刻否掉了「瞬时能量严格等于指数律」的想法——指数函数 E₀e−2λt 在 λE 大于零处的导数处处非零且为负，与转折点上的零导数对不上。

要说清能量去了哪里，还得补一句前提：阻力吃掉的是机械能；如果把介质和它内部的热运动一并算进封闭系统，总能量并没有凭空消失。本节从头到尾算的都是机械能这一本账，不是总能量。

许多坐标同时受阻力，能量的损失怎样写成一本统一的账？

只有一个坐标时，阻力写成 −αẋ 就够了。多自由度系统里，作用在坐标 i 上的速度相关阻力未必只来自自己的速度，一般可以写成所有速度分量的线性组合，即（25.8）：。系数 αik 描述坐标 k 的速度在坐标 i 上产生多大的阻力。真要把每个方向都逐条写下来，会得到一整张系数表，能量损失也只能一项一项地算。耗散函数要解决的就是这件事：把交叉项收进一个标量函数，让「有多少机械能正在被拿走」一步就能读出来。

先从力学照顾不到的地方说起：αik 对下标 i、k 的对称性不能只靠力学论证得到，原文在这里引的是统计物理的结论，本节直接采用互易的耗散模型，即 α 为实对称矩阵（25.9）。这个前提有它的适用边界，不是所有介质都如此。对称性的好处很具体：只有在这个前提下，阻力才恰好是某个速度二次函数的导数，那个函数就是耗散函数。为了不与外力 F 撞名，本页把原书记作 F 的耗散函数改记为 R；反过来，只要一组速度相关的力能从某个标量函数对速度求导得到，那个函数就自动带上对称性。

第一式是 R 的定义，后半段说明它只认速度向量与矩阵的二次型；第二式说明阻力正是 R 对相应速度的偏导再取负号；第三式把这一项加到拉格朗日方程右端，得到有摩擦力时的微振动方程。

为什么损失功率是 2R，而不是 R？

R 里每个二次项含两个速度因子，对某一个速度求导会掉下一个一次因子，再乘回这个速度并对所有方向求和时，每个二次项会被数到两次。系数上的 1/2 就是为这次重复计数准备的。

一维例子可以直接手算：R = αv²/2，阻力是 −αv，它的功率是 −αv²，正好等于 −2R。

量纲单独提醒一次：R 的单位是功率，不是能量。它的取值与速度平方成正比，速度为零时 R 也为零，所以「有阻尼就时刻在耗散」在数值上并不成立。

把三组参数分开，是为了看清「系统带阻尼」这句话究竟担保了什么。

若 α 只是半正定，正实部同样能被排除，但可能出现实部为零的根，也就是一个不耗散的模式，这时不能一口咬定所有运动最终都会消失。再退一步：如果 K 连正定都不满足，稳定势阱这个前提本身就没了，倒置的弹簧即使有阻尼也可能一路离开平衡位置。本节开头用「介质响应足够快、速度足够小」两条保证了方程的写法，它们并不保证解的衰减；衰减要靠上面这些矩阵条件来担保。这样一来，「有没有阻尼」与「哪个方向会衰减」被拆成了两个独立的问题。

结论是弱阻尼下那个平均能量的指数式不能当成一般的瞬时等式，平均与瞬时相差的正是转折点这类时刻。

第二问：取 M = I、K = I 与 α = diag(α, 0)，两个方程分别是 ẍ + αẋ + x = 0 与 ÿ + y = 0。x 坐标受阻尼而衰减，y 坐标是简谐振动，振幅不变，能量守恒。所以「系统带阻尼」不足以断言所有模式都衰减。核验方式很直接：把两个坐标的指数试探解分别代入，得到的 r 分别是 −α/2 加减 i√(1−α²/4)（α 不太大时）与纯虚数 ±i，后者的实部为零；α 的零特征值方向正是这个不耗散的方向。R = αẋ²/2 不小于零只是半正定，确实存在一个不耗散的方向。

这一问同时给主线的两处结论做了条件自检：平均近似只在弱阻尼下成立，多模式的衰减结论依赖 α 正定。

从阻力模型走到「衰减是否必然」的判据

这一步是本节真正的推导落点，中间每一次「注意到」背后都有具体条件：

  1. 介质响应快、速度小 → 只保留与速度成正比的阻力 → 线性黏性方程（25.1—25.3），全节只讨论这一个模型。
  2. 指数试探解 → 特征方程（两个根带 ±√）→ 判别式把运动分成欠阻尼（25.4）、过阻尼（25.6）与临界阻尼（25.7）三类；重根处必须补第二个解，几何上就是振幅多乘一个「一次多项式」因子 t。
  3. 固定同一组初值 → 三类运动共享（x₀, v₀）的闭式解 → 阻尼改变时运动连续变化，交界处由 sin(ωt)/ω → t、sinh(dt)/d → t 衔接。
  4. 直接对机械能求导 → 在 ẋ = 0 之外的地方 Ė = −2mλẋ² 严格为负，而转折点处 Ė = 0 → 只有在弱阻尼下作局部周期平均，才得到平均能量的指数律（25.5）。
  5. 把阻力写成速度的线性组合 → 对称性使阻力成为一个标量函数 R 的导数 → 耗散函数与 Ė = −2R（25.8—25.13）。
  6. 把 R 加进拉格朗日方程 → 多自由度的特征方程 det(Mr²+αr+K) = 0 → 根的实部是否为负由 M、K、α 的条件决定（25.14—25.16）。

本节补上的矩阵条件说明了一件容易被略过的事：开头两条近似保证了方程能写出（25.1）那种形式，而衰减是否必然，取决于恢复力矩阵与耗散矩阵各自的条件。

下一节会把这里的阻尼与 §22 的外力合到一起。需要预先分清的是：本节所有结论都来自自由振动（外力为零），一旦外力持续存在，长期运动由驱动频率与驱动幅度决定，初值只影响衰减掉的暂态部分；那个交界需要正阻尼才干净，零阻尼不能并进来。
