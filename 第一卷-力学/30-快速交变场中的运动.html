第五章 平衡与振动 · §30

快速交变场中的运动：快颤动怎样变成有效势

一个周期里平均为零的力，凭什么能把倒立的摆稳住？答案不在力的平均上，而在质点偏离平均位置的那一小段：它让力在正负两个半周期里作用在不同的地方，差值攒起来，就成了一份新的势能。

平均为零的力，为什么还能改变平衡位置？

先看一个具体的装置。单摆的摆球质量取 m、摆长取 l，把悬挂点沿竖直方向按 a·cos γt 快速抖动，频率远高于 √(g/l)。按最朴素的想法，力在每个半周期换一次方向，一个周期平均下来正好抵消，摆应该照旧在竖直向下的位置附近摆动。可是把抖动开到足够强，竖直向上的那个位置也会变成稳定平衡，摆球会停在上方。要解释这件事，只盯力量的大小是不够的，得看力在什么时候作用在什么位置上：抖动的一正一负两段里，摆球并不在同一个位置；只要力随位置变，这两段的效果就不会严格相消，剩下的那一点就成了慢运动感受到的额外作用。

本节站在第五章的末尾。前面两节处理的都是慢变化：振幅或频率慢慢变，系统在固有频率附近被拖着走，那些公式成立的代价是失谐量 ε 足够小——原书在本节开头先交代了这一点，并指出当力的幅值满足条件 λ²/ω₀ ≪ A/κ ≪ ω₀ 时，阻尼 λ 是小量就足以保证 ε 是小量。本节走到频率范围的另一端：外场的角频率 ω 比慢运动自己的频率高得多，条件是 ωT ≫ 1，其中 T 是质点只在定常场 U 中运动时的周期量级。

把问题写成一般形式。设质点同时受定常势场 U(x) 和随时间变化的高频力 f 的作用，运动方程与力的形式见下式。其中 f₁、f₂ 只是坐标的函数：随时间变化的部分必须是纯振荡的，不随时间变化的部分已经归进 U 里。原书特别指出，并不假设 f 的幅值比 U 产生的力小，两者的量级可以相当；真正被要求小的是这个力造成的振动位移 ξ。也就是说，下面这对公式承担的力学假设其实只有一条，而它要在整节里反复核对。

关于形式再补一句：只写一个余弦项不足以表示一般的高频力，因为力的相位是任意的。写成 f₁cos ωt + f₂sin ωt，相当于振幅 √(f₁²+f₂²)、相位由 f₁ 与 f₂ 共同决定的一支单频振荡力；把计时起点平移，只会让 (f₁, f₂) 转一个角度，而最后的有效势只依赖 f₁²+f₂²。结果不随计时起点改变，这本身也是一次自检：真正进入物理的只有力的振幅，不是它在某一时刻的瞬时值。【补充·自编】

本节最后要回答的，就是那个看着别扭的问题：一个平均为零的快变力，怎样在慢运动里留下一份可以写成势能的东西。原书两题给的答案是同一个机制的两个侧面——竖直抖动支点，会在原本不稳定的倒立点挖出一个势阱；水平抖动支点，会把向下的那一个势阱劈成左右两个。

把 x 拆成 X+ξ 之后，哪一项不能丢？

先在一条直线上把问题算清楚。质点受定常场的力 −dU/dx 与高频力 f(x,t) 同时作用，运动方程就是上面那一对公式的前一式。从力场的性质可以看出运动的形状：质点沿着一条平滑的轨道缓慢前进，同时围绕这条轨道做频率为 ω 的小振动。于是把真实位置写成两部分之和，x(t) = X(t) + ξ(t)，这正是原书的 (30.3)。ξ 是围绕轨道来回颤动的部分，它在一个快周期上的平均为零；X 在这段时间里变化很小。用字母上划线表示时间平均，就有 x̅ = X，也就是说，X 描述的是把快速振动抹平之后的那条平稳运动。

把 x = X + ξ 代进运动方程，再把定常场的力和高频力都在 X 处作泰勒展开、只保留 ξ 的一次项，就得到下式。左端出现两个加速度；右端有四种来源：定常场的力、定常场力的修正、高频力本身、以及高频力随位置的变化。写成这样以后逐项判断大小，比笼统地说一句「ξ 很小，都可以丢」要可靠得多。

顺带看一眼快速度：。它与慢速度组成的交叉项在平均之后归零，因为 ξ̇ 在一个快周期上的平均为零，而 Ẋ 在整个窗口里变化很小；但它自己的平方平均不会消失——下一段会看到，那正是有效势增加的那一份。判断一项去留时，看的是它在平均之后还剩什么，不是它单独看起来有多大。

快变部分的领先阶方程只有一项力：mξ̈ = f(X,t)，即原书的 (30.5)，其中 X 被当成常数。由于 f = f₁cos ωt + f₂sin ωt 是纯单频振荡，对时间求两次导数等于乘 −ω²，所以下式直接满足它。积分时出现的常数项和匀速项都属于 X，不必再算进 ξ 里，否则同一段运动会被记两遍。

这个结果同时也给出一把量尺： 约为 f/(mω²)，它必须远小于 U 和 f 在空间上有明显变化的那个长度，把 f 按 ξ 展开才站得住。频率高并不能单独保证这一点：如果力的幅值也随频率按 ω² 一起长，f/(mω²) 根本不会变小，这时要看的是外场的几何幅度。时间尺度（ωT ≫ 1）和空间尺度（快位移远小于场的变化长度）各管各的，满足了前一个不能替后一个作保。

「对一个快周期取平均」，到底固定了什么？

要把「平均」写成能计算的东西，先得说清三件事：平均什么、在什么窗口上平均、窗口里什么被当成常数。

第一，窗口长度 Δt 要落在两个尺度之间：上界是慢时间 T，下界是快周期 2π/ω。下界保证窗口里装得下许多个快周期，快振动的细节被抹平；上界保证 X 在这段时间里几乎没走出去，可以说「质点此刻在 X 附近」。

第二，窗口之内把 X 固定，于是所有对时间的平均都只作用在 cos ωt、sin ωt 这类量上：一次项的平均为零，平方项给出 1/2，正弦乘余弦还是零。X 的函数在窗口里是常数，可以提到平均号外面。

第三，这是局部时间尺度上的近似，不是把质点真的冻结在 X 上。对每一个 X 都存在一支略有不同的快振动解，真正的运动是在这一族解之间缓慢移动过去。所以平均后的方程描述的是「在一族小振动背景上的漂移」，而不是原来那个势里的一条轨道。

举一个最小的例子，把「平均为零、乘积不为零」看清楚：取 f = A(X)cos ωt，则 ξ = −A(X)cos ωt/(mω²)。⟨f⟩ 和 ⟨ξ⟩ 单独看都是零，可它们在平均号里的乘积不是零：⟨ξ∂_X f⟩ = −AA′/(2mω²)。这一项带着 A 的导数，A 不随位置变时它立刻归零。慢运动感受到的正是它。

需要冻结的是短时间窗口里的慢坐标 X，不是让质点真的停在那里。取窗口时要求 ：窗口里装得下许多个快周期，可以使快振动的细节被抹平，同时 X 几乎没走出去。对每一个 X，都存在一支略有不同的快振动解；所谓慢轨迹，就是在这一族局部解之间缓慢移动过去。这样看，慢运动并不是在原来的势里走，而是在一族各不相同的小振动背景上被挪动。

平均之后剩下的那一项，为什么是一份势能？

把展开后的方程对整个快周期取平均。ξ 自己的平均为零，f 的平均也为零，ξ̈ 在窗口里的平均同样是零（ξ 有界且周期变化），于是 U″ξ 这一项在本阶消失；唯一留下来的是快位移与力场空间梯度的乘积的平均 ⟨ξ∂_X f⟩。方程只剩一个未知函数 X。

这一项也可以换个角度读，更容易看出它为什么不为零。质点并不待在平均位置 X 上，它感受到的是 f(X+ξ,t)；把这一项在 X 处展开到一阶，就多出 ξ∂_X f(X,t)。力自己的平均是零，可这一项不是零，因为它与 ξ 成比例，而 ξ 又正比于 f：乘积里出现的是 f 的平方，平方的平均当然不为零。把 ξ = −f/(mω²) 代进去，并注意 f∂_X f = ½∂_X(f²)（求平均时 X 被冻结，对 X 求导与对时间求平均互不干涉），这一项就化成 −(1/(2mω²))·d⟨f²⟩/dX。它正好是一个新势能的负梯度，于是慢方程可以写成只含 U_eff 的形式。

把平均算出来就更具体。f² 展开后有一项正弦乘余弦，它的平均是零；两个平方项各给出 1/2。于是 ⟨f²⟩ = (f₁²+f₂²)/2，有效势里的修正项就是 (f₁²+f₂²)/(4mω²)。整个推导只用到一条性质：随时间变化的那部分力是单频纯振荡，f₁、f₂ 只是坐标的函数。力的具体形状并没有被用到，所以 (30.8) 对任何满足 (30.1) 的力都成立。

修正项恒为非负，它是「力振幅有多大」的度量。但推动慢运动的是它的空间梯度，不是它的大小：若 f₁、f₂ 都是常数，这项只是把势的零点整体挪了一下，慢运动一点额外的力都不受；若振幅随位置变大，新增的力就指向振幅较小的那一侧。可以把它读成一句话：快速振动剧烈的区域会把质点往外推。

修正项还有另一种写法，能直接看出它的物理身份。把 ξ 对时间求导，正弦与余弦互换；因为 f 是单频振荡，⟨ḟ²⟩ = ω²⟨f²⟩，平方量的平均仍旧给出两倍关系，整理后得到下式：有效势的增加量恰好等于快颤动的平均动能 (m/2)⟨ξ̇²⟩。于是「快速抖动」的动能在慢运动的方程里扮演了势能的角色。这里用到 ⟨ḟ²⟩ = ω²⟨f²⟩，它依赖 f 是单频振荡；换成一般的周期力，这个等号不再逐项成立，必须回到 ⟨ξ∂_Xf⟩ 去算。

要说明白的是，U_eff 不等于「把总能量逐项平均一下就得到的一份守恒能量」。真实系统仍被外场驱动，能量不断进出，瞬时能量照旧上下起伏。U_eff 是从平均后的慢方程里辨认出来的领先阶结果，它管的是慢变量在这一阶上的行为；只有把快变量平均掉，慢系统才在这一精度下表现得像在定常势中运动。原书把这条平均方法记在卡皮查名下，出处见本节脚注②（卡皮查，1951）。

快运动增加的是动能，为什么在慢运动里却被记成势能？

这句话容易被读成「把快动能平均一下、换个名字」。可以换一条路验算符号和系数：从拉格朗日函数出发，把驱动力的来源也写进去。驱动势 V 本身随时间振荡，它作用在颤动着的质点上，平均下来并不为零；真正进入有效拉格朗日函数的是快动能与驱动势平均贡献之和，而后者更大，并且取负号。下图把这三项的相对大小排在一起，先看清结构，再看推导。

最后做一次独立的物理核对。如果 K 与 X 无关，它在拉格朗日函数里只贡献一个常数，慢运动不会因此多出任何力；如果 K 随 X 增大，慢力 −K′ 就指向快振动能量较小的区域。这个方向与前面从力和位置的相关性算出来的完全一致——新增的力指向振幅较小的一侧——两条路走到同一处，说明符号和系数没有弄反。

换成摆角，惯性系数该填哪个量？

到目前为止，坐标都是一条直线上的长度，前面的系数是一个常数 m。真正用到摆上时，坐标换成摆角 φ，动能写成 (ml²/2)φ̇²——扮演「质量」角色的是转动惯量，右端的驱动量则换成广义力矩，量纲已经是能量。一般的系统用广义坐标 q_i 描述，动能是 ，其中 a_ik(q) 是惯性系数，也就是质量或转动惯量在任意坐标下的推广。把慢坐标冻结住，快响应满足 a_ik ξ̈_k ≈ f_i(X,t)；因为每个 ξ_k 都是单频振荡，这组方程化成代数方程 −ω²a_ikξ_k = f_i，解出来就是 。

代回平均后的方程，多自由度的有效势就是下式，也就是原书的 (30.10)：U_eff = U + (1/(2ω²))·(a⁻¹)_ik⟨f_i f_k⟩ = U + ½·a_ik⟨ξ̇_i ξ̇_k⟩。第二个写法可以由第一个代进去、再用 a_ik(a⁻¹)_kj = δ_ij 验证，两者是同一件事：一个是「按力算」，一个是「按快动能算」。

这里的 a⁻¹ 是整块矩阵的逆，不是把每个系数单独取倒数——一般情况下两者完全不同。矩阵能求逆，靠的是独立坐标下动能的正定性：速度不全为零时动能必为正，于是矩阵可逆。只要坐标取得独立，这一步不需要额外假设。下面这个插件用最小的例子把「整块求逆」和「逐项取倒数」的差别算一遍。

惯性矩阵求逆：为什么不能逐项取倒数？

先看它要解决什么问题。两个坐标之间有惯性耦合时（a₁₂ 不为零），单独推第一个坐标也会带动第二个坐标，所以「哪个坐标响应多少」不能一个一个算，必须解联立方程。把快响应方程 a_ikξ̈_k = f_i 在单频下化成代数形式 −ω²a_ikξ_k = f_i，解就是 ξ = −a⁻¹f/ω²：力的分量先被整块矩阵的逆混合一次，才变成各坐标的位移。

最小例子：取 a 的两个对角元都是 2、两个非对角元都是 1（同一个单位下）。行列式是 2×2 − 1×1 = 3，逆矩阵是 (1/3) 乘以「对角元 2、2，非对角元 −1、−1」。验算一次乘法：对角元 (2×2 + 1×(−1))/3 = 1，非对角元 (2×(−1) + 1×2)/3 = 0，确实得到单位矩阵。

若改成逐项取倒数，得到的矩阵是对角元 1/2、1/2，非对角元 1、1。把它与 a 相乘，对角元是 2×0.5 + 1×1 = 2，非对角元是 2×1 + 1×0.5 = 2.5，与单位矩阵相差很远，恢复出来的力也就不对了。

什么时候两者恰好相同？只有当 a 是对角矩阵、坐标之间没有惯性耦合的时候。非对角元越小，逐项取倒数越接近正确答案，但一般情况下不能省略这一步。【补充·自编】核验方式：直接做上面两次 2×2 矩阵乘法，再与「正定性保证可逆」这一条对照——行列式 3 不为零，正是动能正定在矩阵上的表现。

把前面的推导连起来，整节到底得到了什么？

整节只有一条推导链，可以压缩成六步。第一，辨认两个时间尺度：外场周期 2π/ω 远小于慢时间 T，同时把快位移当成小量——这是全节唯一被假设小的力学量。第二，把位置拆成 x = X + ξ，冻结 X 求快振动：mξ̈ = f(X,t)，得到 ξ = −f/(mω²)。第三，回到慢方程取平均：⟨f⟩、⟨ξ̈⟩、⟨U″ξ⟩ 都消失，只剩 ⟨ξ∂_X f⟩。第四，用 ξ 的表达式把它改写成 −(1/(2mω²))·d⟨f²⟩/dX，也就是 −dU_eff/dX，于是 U_eff = U + ⟨f²⟩/(2mω²) = U + (f₁²+f₂²)/(4mω²)，并且等于 U + (m/2)⟨ξ̇²⟩。第五，从 U_eff 的极小判断慢运动的稳定性；遇到二阶导数为零的临界参数，改看高阶项。第六，回头核对条件：新的慢频率是否仍远小于 ω，快位移是否仍远小于场的空间尺度，摆题里还有 a/l ≪ 1。

原书 (30.1)–(30.10) 走的正是这条路：先写出高频力与运动方程，再分解、展开、对快周期取平均，识别出有效势，最后推广到广义坐标。整节最要紧的一句是：力的瞬时平均为零，并不等于平均作用为零。真正留下来的是力与「质点偏离平均位置」之间的相关性——⟨ξ∂_X f⟩ 正比于 −d⟨f²⟩/dX，而它恰好可以写成一份势能的梯度。

这一节在第五章里的位置也值得说明。本章前面用过好几种描述平衡附近运动的办法：简正模式（§23）、受迫振动与共振（§26、§27）、参数共振（§27）、弱非线性与近共振（§28、§29）；本节补上频率范围的另一端——快慢分离下的平均。到底选哪一种描述，取决于系统的频率比、振幅和能量往哪里流。本节这套平均办法的适用面很窄：力要是周期性的，两个时间尺度要分得开，快位移要足够小。原书两道题把结论用在同一个具体系统上：同样快速抖动支点，竖直方向抖动会在倒立点挖出势阱，水平方向抖动则把向下的势阱劈成两个斜位；两个阈值都落在 a²γ² = 2gl，但「临界」的含义一处是退化极大、一处是退化极小。
