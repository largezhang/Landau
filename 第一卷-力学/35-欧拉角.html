§35 三个角怎样把刚体的朝向说清楚？

姿态换成三个角只是第一步；要用它算角速度、写动能、化成一维运动，靠的是同一瞬间的三份角速度可以相加，以及对称性把 ψ 从动能里去掉。

前置：§32 的角速度与转动动能、§33 的对称陀螺自由运动（θ 不变、进动角速度 M/A）、§34 的力矩与角动量定理；上一节给的是「力矩怎样改变角动量」。本节先搭姿态角到角速度之间的几何桥，再用有重力的对称陀螺走一遍从 L 到一维有效势的完整计算。正文直接可读；工具与答案按需展开，点击公式可复制。

为什么不满足于「转得有多快」

一支粉笔立在桌上。你说它「转得很快」，这句话可能指三件完全不同的事：它绕自己的长轴自转、长轴在慢慢绕竖直方向画圈、长轴还在上下点动。三个动作的量级可以差出几个数量级，只报一个角速度的大小，既不能判断外壳上的标签此刻朝哪里，也无法预测下一刻的姿态。

上一节已经给出外力矩怎样改变角动量。要把这条规律用到看得见的陀螺上，中间缺一座桥：先要有办法把「朝向」写成一串可求导的数，再由这串数及其变化率算出同一时刻的角速度，然后才谈得上动能、角动量和运动方程。§32、§33 里角速度是给定的输入，本节第一次让它由姿态角的变化率决定。

桥上有两处容易踩空，这里先点名，后面各自展开。第一处：三个姿态角的变化率并不是角速度的三个分量，因为三个瞬时转轴既不互相垂直，方向还随姿态改变；第二处：对称陀螺的动能里可以完全不出现 ψ 本身，这不是代数上的巧合，而是轴对称的直接结果。本节前四段把这两点做实，末两段用它把重对称陀螺化成一维运动问题。原书在本节给出的正是这条路线：定义欧拉角（35.1 之前的几何约定）→ 角速度分量（35.1）→ 转动动能（35.2）→ 简化写法（35.3）→ 自由对称陀螺（35.4）→ 三道附解习题。

朝向要用哪三个角来量？

刚体有一个点固定时，它只剩三个转动自由度：位置不再是问题，要交代的只有朝向。把一组直角坐标轴固定在实验室里，记作 X、Y、Z；再一组固定在刚体上，取惯量主轴为 x₁、x₂、x₃，让 x₃ 沿对称轴。两组轴共用固定点为原点，朝向问题就变成「动系相对定系的取向」。

两个坐标平面总有一条交线：实验室的水平面 XY 与刚体的赤道面 x₁x₂ 相交于一条直线，称为节线，记作 ON。它同时垂直于 Z 和 x₃，方向取 z × x₃（z、x₃ 是两个轴方向的单位矢量）。有了这条线，就能用三个角把两套轴的关系说全：θ 是 Z 轴与 x₃ 轴的夹角，φ 是 X 轴与节线的夹角，ψ 是节线与 x₁ 轴的夹角。φ 按绕 Z 轴的螺旋方向量，ψ 按绕 x₃ 轴的螺旋方向量；θ 从 0 取到 π，φ 和 ψ 各自从 0 取到 2π。

这样量出来的一串角，读法是「两步找到轴，一步定住外壳」。φ 和 θ 只负责把 x₃ 轴指到一个方向：θ 给出偏离竖直多少，φ 给出这个偏离朝着哪个方位。轴的方向定完以后，刚体还能绕这根轴转，这一份自由度由 ψ 承担。若只报出轴的方向，外壳上刻的记号朝哪一边仍然未知，这正是粉笔例子里「转得快」说不清的部分。下面的三维模型把这三步做成分层按钮：每按一层，多显出一步转动和一根体轴，可以逐步对照。

定义里还藏着一处必须提前交代的退化。θ 取 0 或 π 时，x₃ 与 Z 重合或反向，两个坐标平面的交线不再唯一，节线失去了确定方向，「X 到节线的夹角」也随之失去意义。这时物体本身没有问题，姿态仍然连续；出问题的是这套坐标的写法：只有 φ 与 ψ 的组合（例如 φ + ψ 或 φ − ψ）才有物理意义，单独一个 φ 或 ψ 无法独立确定。后面遇到 sinθ 作分母的式子，不能在这一点上硬除，到时另作处理。

图上先把三根轴各自的身份认准：Z 与 x₃ 的夹角给出 θ，节线在水平面里的方位给出 φ，x₁ 相对节线的转角给出 ψ。三个角的取值范围和正方向都要跟着这张图走，中途换一个正方向，后面的投影式和守恒式会跟着改号。

观察时先做两个小检验。只改 ψ、保持 φ 和 θ 不动：x₃ 指向不变，物体绕自己的轴转，总角速度应当沿 x₃。只改 φ、保持 θ 和 ψ 不动：整个姿态绕实验室的 Z 轴转过去，虽然此时体轴上的三个分量可能都不为零，总角速度的方向仍应沿 Z。这两个检验与图上的读数可以互相校对。

三个角的导数直接当角速度用，会漏掉什么？

要把 θ̇、φ̇、ψ̇ 合成总角速度 Ω，先回答一个更基本的问题：有限大的两个转动能不能像矢量那样相加？不能。绕两根不同轴各转 90°，交换次序得到的结果并不相同，所以「先转 φ 再转 θ」与「先转 θ 再转 φ」不是同一个姿态，有限转动本身不是矢量。

真正可以相加的是同一瞬间的三份角速度。把上述三步看成在极短时间内的三次微小转动：φ 增加了 Δφ，姿态改变 Δφ 乘绕 Z 的转轴；θ 增加了 Δθ，改变量绕节线；ψ 增加了 Δψ，改变量绕 x₃。两次微小转动次序交换带来的差别是二阶小量，只留一阶时消失了，于是同一瞬间的三份角速度可以放在同一个空间里相加：Ω = φ̇e_Z + θ̇e_ON + ψ̇e₃。这里 e_Z、e_ON、e₃ 是三个瞬时转轴的单位矢量，前两个在动系里还会随时间改变方向；「同一瞬间」这四个字是这一步成立的全部理由，不能推广到有限转动。

相加以后还要取分量，因为需要写体轴上的 Ω₁、Ω₂、Ω₃（转动动能用的是体轴分量，惯量张量在这组轴上是对角阵）。做法是把三份角速度分别投影到 x₁、x₂、x₃ 上：θ̇ 顺着节线，φ̇ 顺着 Z，ψ̇ 顺着 x₃。投影的结果就是下面的（35.1）。这里要强调的是操作顺序：先在同一瞬间把三份角速度相加，再投影；反过来先投影到体轴再相加虽然也对，但换个姿态约定就要重投一遍，而三个瞬时转轴的身份不会变。

例如节线方向的单位矢量在 x₁、x₂ 上的分量是 cosψ 与 −sinψ，第三个分量是零，于是 θ̇ 只落在前两个方程里；Z 与 x₃ 夹角为 θ，所以 φ̇ 在 x₃ 上留 cosθ，另外 sinθ 那一份落在赤道面内、方向垂直节线，投到体轴上得到 sinθsinψ 和 sinθcosψ 两项。ψ̇ 只沿 x₃。把三列分别乘对应的变化率再相加，就是（35.1）的三个分量，每一项都能指回一根具体的转轴——这是符号记不清时最可靠的核对方式。

再补一个特例检验：让 x₁ 这一瞬间正好取在节线上，即取 ψ = 0，于是节线方向的分量最简。此时（35.1）退化成 Ω₁ = θ̇、Ω₂ = φ̇sinθ、Ω₃ = φ̇cosθ + ψ̇，三项各由一根转轴单独贡献。这个写法只是当前瞬间的一次选轴，用完就该放下：下一瞬间节线已在球面上挪了位置，再声称 x₁ 与它重合就不再成立。

回到当前推导。至此已经有了从姿态角变化率到角速度的换算表，而实验上直接读数的量（角动量、动能）都是用 Ω 的体轴分量写的，所以这张表就是本节要搭的那座桥。下一段把它代进转动动能，看轴对称会替我们省掉哪一项。

轴对称替我们省掉了哪一项？

把（35.1）代进转动动能 T = ½Σ IᵢΩᵢ²。对一般的三轴刚体，这一步会留下一堆含 ψ 的交叉项，动能既依赖 ψ 也依赖 θ、φ。对对称陀螺 I₁ = I₂ ≠ I₃，情况立刻简化：物体绕 x₃ 转一个方位，质量分布没有任何变化，所以转动能不可能依赖 ψ 本身——代数上出现的交叉项恰好抵消，抵消所依据的正是这条空间对称性。

两个横向速度的来源可以分开看：一个是倾角本身的变化 θ̇，一个是轴在球面上沿纬线移动的速度 φ̇sinθ。两者方向相互垂直，平方时直接各自平方相加，系数都是 A/2。轴向角速度是 ψ̇ 加上进动沿 x₃ 留下的投影 φ̇cosθ，系数是 C/2。注意同一个 φ̇ 同时出现在两类项里：它既让轴在纬线上移动（横向），又沿 x₃ 留下一份分量（轴向）。只把 φ̇ 放进其中一类，能量就会漏账。

对称性还有一项立即可见的后果：ψ 不出现在动能里，也不出现在势能里（势能只与质心高度有关，绕 x₃ 转不改变高度），所以 ψ 是循环坐标，p_ψ = C(ψ̇ + φ̇cosθ) 守恒。这一条在下一段的重陀螺里会直接用来降维。记住这条守恒的适用范围是轴对称加上固定点；三个轴惯量互不相等的刚体没有这份守恒，届时必须回到（35.1）逐项算。

先拿一个已经完全算过的例子检验这套写法：§33 用矢量方程求出的对称陀螺自由运动。取实验室的 Z 轴沿定常角动量 M，动系的 x₃ 沿陀螺对称轴，并让 x₁ 在给定时辰与节线重合（ψ = 0）。此时 M 的三个体轴分量为

M₁ = 0、M₂ = M sinθ、M₃ = M cosθ。

第一式为零是因为节线同时垂直于 Z 与 x₃，M 沿 Z，自然没有节线方向的分量。另一方面由（35.1）的 ψ = 0 简化式算出 M₁ = I₁θ̇、M₂ = I₂φ̇sinθ、M₃ = I₃(φ̇cosθ + ψ̇)。两组式子逐项对比，就得到

θ̇ = 0、I₁φ̇ = M、I₃(φ̇cosθ + ψ̇) = M cosθ。（35.4）

第一式说明陀螺轴与 M 的夹角保持不变，与 §33 的结论一致；第二式说明进动角速度 φ̇ = M/I₁，也与 §33 的（33.5）相同；第三式给出绕自身轴的转动角速度 Ω₃ = M cosθ/I₃。三个式子合起来就是「轴绕 M 画圆锥、圆锥半顶角固定、外壳同时在自转」这幅图像。这里正好看清前一段那句话的意思：转动的快慢不止一个数，φ̇ 和 Ω₃ 是两个不同的频率，把 x₁ 取在节线上只是让当下的分量表达式最短，并不改变这两个频率。

重力一进来，为什么只剩一个角要解？

现在让陀螺的下端点固定，重力开始起作用。支点不动，所以不做功，但取矩点变了：横向惯性必须从质心值换成对支点的值。用平行轴定理，垂直于对称轴的惯量由 A 变成 A + μl²（记作 A′），沿对称轴的 C 不变，因为质心就在这根轴上、距离为零。这一步最容易漏，同一根轴从质心量和对支点量，数值确实不同。

重力作用在质心，方向竖直向下；θ 从竖直向上量起，所以质心高度是 lcosθ，势能为 μglcosθ。取 Z 沿竖直向上，拉格朗日函数写成

L = A′(θ̇² + φ̇²sin²θ)/2 + C(ψ̇ + φ̇cosθ)²/2 − μglcosθ。

三项各有身份：横向转动能、轴向转动能、重力势。写下来立刻可以看出 φ 和 ψ 都不出现，而 θ 出现了两次（高度和横向几何系数）。于是只有 φ、ψ 是循环坐标，各自给出一个守恒的共轭动量。

这两个守恒量分别是角动量在竖直轴和对称轴上的投影，守恒的理由并不相同。φ 只改变整个装置在水平面里的方位，绕 Z 转过去，动能和势能都不变，所以 p_φ 守恒，它对应空间转动对称性；ψ 只改变轴对称外壳绕自身轴的朝向，对轴对称的质量分布毫无影响，所以 p_ψ 守恒，它对应物体自身的轴对称性。这一点必须逐个说明，不能记成「有三个角就有三份守恒角动量」：θ 恰恰是破坏对称性的那个角，它一动，质心高度就变。还要交代限度：整个角动量 M 是会被重力矩改变的，守恒的只有它的这两个投影。

这里 a 与 b 都与时间无关，可以把它们当成两个给定常数。求解顺序很具体：先由 a 解出组合 ψ̇ + φ̇cosθ，再由 b 解出 φ̇，最后把这两个结果塞回总能量。顺序不能颠倒，因为 a 锁住的是两者的组合而不是 ψ̇ 本身，单看 a 无法知道自转多快。把速度项都换成 a、b 的函数以后，能量方程里唯一剩下的未知速度就是 θ̇：

这就是把三个角的问题缩成一个的过程。等效势里的第一项来自横向角动量：给定 a 和 b 以后，要让轴停在倾角 θ 上，横向那部分转动能必须取这个值，所以它由两份投影的差额决定；第二项 μglcosθ 才是真正的重力势。两项来源不同，不要混着谈「势垒是重力造成的」。ℰ 是从总能量里减掉轴向常数 a²/(2C) 得到的约化能量，减掉的是守恒量，不影响运动方程。

看图的方法是画一条水平线代表 ℰ。能量线以下的 θ 是允许的，交点处 θ̇ = 0，称为章动转向点；两个转向点之间往返就是章动，而 φ 随 θ 变化不断推进就是进动，两者叠起来才是肉眼看到的运动。θ 的允许区间完全由 ℰ 与 V 的高低决定，与初始角速度的细节无关——初始条件只决定 ℰ 落在哪条水平线上。这一套办法与第三章的有效径向势完全相同：先用循环坐标消元，再解一维运动，只是把径向坐标换成了倾角。

势垒的形状还有一层几何含义。想让体轴靠近竖直方向，就得让两份投影的方向逐渐重合；若 a 与 b 不相等却仍要求各自保持不同的数值，横向转速必须越来越大，上极点处的势才随之发散。b = a 时这个冲突消失，上极点不再发散；下极点方向相反，条件相应变成 b = −a。这两个特殊条件不是两条需要硬记的公式，而是「两个投影方向相同时不发生冲突」的直接翻译。

各量之间的关系还可以用一套具体数字核对一遍，这也是检验「哪条守恒式管哪个速度」最直接的办法。【补充·自编】下面这一组数值不是原书内容，只是把（35.4）与（35.5）当公式用一次；核验方式列在每步之后。

两条链各自到哪里为止？

本节有两条应当能自己复述的链。几何链是「三个角 → 三根瞬时转轴 → 同一瞬间相加得到的 Ω → 转动动能」；它只用姿态角与角速度的换算关系，对任何刚体都成立，不需要轴对称，也不需要固定点，条件是同一次运算里所有量取自同一时刻。不要把它说成「三个角的导数就是角速度」，那正是本节开头点名要避免的误解。

动力学链是「对称性 → 两个守恒投影 → 倾角的一维有效势 → 反解出 φ 与 ψ」。它多用了两条前提：轴对称以及一个固定点。离开轴对称，ψ 不再是循环坐标，上一句「由守恒量解出 ψ̇」就没有依据；离开固定点，平行轴定理那一步也要换。复述时分清这两句的适用范围，就不会把特例当成普遍规律。

一维问题本身还没解完：θ(t) 由一次求积给出，是椭圆积分；φ 和 ψ 再由各自的积分补上，三个初始角和三个初始角速度先决定 a、b、ℰ 及初相，求积并没有丢掉初态信息，只是换了三个待定常数来记录它。转向点附近的行为也分两类，普通转向点处能量差正比于到端点的距离，积分像根号，有限时间就能到达；若到达的是势的极大值且能量恰等于该值，能量差可能正比于距离平方，时间积分出现对数发散，说明逼近它要花越来越久。原书题 1、题 2 分别处理这两类边界。

下一节会换一套未知量：不再追姿态角，而是直接写随体坐标系的角速度分量，让惯量张量保持常对角阵，代价是守恒量的形式要重新找（转动坐标系里的导数多出一项 Ω ×）。两条路线的长处不同：欧拉角路线擅长把对称性写成循环坐标，欧拉方程路线擅长直接分析转动分量的演化。它们描述的是同一个运动，最后都要能恢复真实姿态，选哪条只看哪一种量更省事。

完整解答与自检

一阶近似下忽略重力，陀螺轴绕角动量 M 方向自由进动，由（33.5）得快进动角速度 Ω = M/A′。下一级近似里出现 M 绕竖直方向的慢进动。为了求它，把精确的运动方程 dM/dt = K 按快周期平均，重力矩为 K = μl n₃ × g，其中 n₃ 是沿陀螺轴的单位矢量。

在一个快周期里，n₃ 绕 M 画出圆锥，扫过各个方位；对时间求平均后，垂直于 M 的分量互相抵消，只剩沿 M 的那一份：平均 n₃ = cosα M/M。把平均方向代进力矩，得平均方程

右端的系数就是慢进动角速度矢量。它与 Ω = M/A′ 的比约为 μl/M² 的量级（相差一个几何因子），所以只要自转足够快、重力微扰足够小，快慢尺度确实分得开；分不开时这次平均无效：慢变量在一个「快」周期内已经明显变化，把它当常数就不再是好的近似。
