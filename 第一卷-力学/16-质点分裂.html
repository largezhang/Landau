不知道分裂时的作用力，还能算出什么？

先看一个能拿在手上的装置：一块静止的物体由两个小块组成，中间压着一根锁住的轻弹簧，两块质量分别是 m₁ 和 m₂，外面不加任何东西。松开锁扣，弹簧把两块推开，它们朝相反的方向飞走。我们既不知道弹簧的劲度系数，也不知道它推了多久，更不去追问这一瞬间内部到底发生了什么。可用的只有两条：分裂前后总动量守恒，总能量守恒。本节要问的就是这件事——只靠这两条，末态的运动能被限定到什么程度？

这里说的分裂是「自发」的：没有外力做功，也没有外界触发。最方便的做法是先坐到「分裂前那块物体静止」的参考系里去，也就是系统的质心系，习惯上记作 C 系。在这个系里分裂前总动量为零；分裂后两块作为自由质点①飞走，总动量必须仍然为零，于是两块动量大小相等、方向相反。用单位矢量 n 记下其中一块飞出的方向，共同的动量大小记作 p₀，两块各自的内能记作 E₁int 与 E₂int，分裂前那块物体的内能记作 E_int，把能量守恒写成

式中的前两段只是把两块动量写成 p₀n 与 −p₀n；最后一段定义的 ε 是「分裂能」，也就是内部结构的能量账里能拿出来变成平动动能的那一部分。两块飞开之后不再相互作用，它们之间没有势能可谈，凡是没有变成平动动能的能量都记进内能。

分裂能全部进入两块的平动动能。把两块的动能加起来，折合质量就冒出来了：

由此 p₀ = √(2με)。原书把这个约化质量写作 m，本页改用 μ，免得和子粒子的质量 m₁、m₂ 混在一起。这里还有一件必须交代的事：只有 ε 大于零，两块才会真的分开飞走。ε 小于零意味着按给定的内能账目能量根本不够，这个自由末态不成立；ε 等于零时 p₀ = 0，两块相对静止，是刚好卡住的门槛。反过来，ε 大于零只说明运动学上允许，它管不了分裂会不会发生、以多大概率发生、朝哪个方向发生——那几件事由具体的内部机制决定。本节从头到尾都在非相对论范围内：质量直接相加 M = m₁ + m₂，不引入相对论质量，也不把内能换算成质量亏损；比较的又都是分裂完成、两块自由飞开之后的末态，忽略残余相互作用与外界做功。

这三条可以从 (16.2) 直接推出来：T₁₀ = p₀²/(2m₁) = 2με/(2m₁) = εm₂/M，另一块同理，两者之比就是 m₂ 比 m₁。拿一组数验算一下：取 m₁ = 1、m₂ = 3、ε = 4（单位一致），则 μ = 3/4，p₀² = 2με = 6，两块动能分别是 3 和 1，加起来正好是 4。轻的那块反而分到更多动能，看起来与「同速度时重的动能大」相反；其实两句话固定的量不同：这里两块动量一样大，那里两块速度一样大，各自的情形各自算。

别忘了分裂之前那块物体本来就带着 ½MV² 的平动动能，所以总能量依然守恒。但两块各自的实验室动能并不固定：一块的动能随着它相对 V 的飞出方向而变，而这正是后面要算的分布。

同一条探测方向，为什么可能对应两个速率？

在实验室里，探测器只告诉你「有一块朝这个方向飞出来了」，速率得自己反推。只挑其中一块来看：它在 C 系里的速率记 v₀（由前面 (16.2) 的账目给定，在一次分裂里是个确定的数），在实验室系里的速率记 v。取 V 的方向为 x 轴，θ₀ 是它在 C 系里飞出的方向与 x 轴的夹角，θ 是实验室速度与 x 轴的夹角，两个角都取 0 到 π。把速度按 x 方向与垂直方向分解：

最后一个式子的来历很直接：三个速度矢量满足 v = V + v₀，把两边与自身作点积就得到 |v − V|² = v₀²，展开即 (16.3)。它在速度空间里的含义很清楚：所有可能的 v 矢量，端点都落在以 V 的端点为球心、以 v₀ 为半径的球面上。于是「给定方向求速率」变成了「从实验室速度零点 A 出发的射线，与这个球面有几个交点」。

反正切与开平方，各自会丢掉什么信息？

先看象限。取 v₀ = 2、V = 1、θ₀ = 120°：横向分量是 v₀ sinθ₀ = √3，纵向分量是 V + v₀ cosθ₀ = 1 − 1 = 0，实验室速度正好垂直于 V，θ 应当是 90°。这时若只用「横向除以纵向」去取主值反正切，分母为零，方向信息直接丢掉；再把 θ₀ 加大，纵向分量转成负的，θ 进入钝角，而主值反正切只会给出一个锐角或负角，把这个钝角折回去。数值实现里要写 atan2(垂直分量, 纵向分量)，让它同时看两个分量的符号来定象限；写错的话，后面整片分布都会跟着偏。

各向同性说的是立体角，为什么均匀的却落在 cosθ₀ 上？

到这里为止描述的都是「一次」分裂：给定了 ε 和 V，每一块的速率由方向唯一决定。可是守恒律对每一次分裂都成立，却不决定方向朝哪儿指。真实实验里是很多次相同的分裂，要谈分布就必须另外补一条统计假设，否则这件事无从计算。原书补的假设是：原始质点在空间中的取向随机，平均看来是各向同性的。要留意这句话说的是每次分裂在它自己的 C 系里发射方向没有偏好，而不是让实验室里的束流方向 V 也去随机化；把两者混在一起，算出来的就是另一类问题。本地转写稿把这句写成「原始质点在空间中运动方向是随机的」，按上面这层意思理解才准确。补上这条假设之后，问题在 C 系里变得很简单：同一类型的子粒子能量都是同一个值 mᵢv₀²/2，只有方向随机，分布问题退化成纯几何的计数。

各向同性的意思是等立体角等概率：落进立体角元 dΩ₀ 的概率等于 dΩ₀ 除以球面总面积 4π；代入 dΩ₀ = 2π sinθ₀ dθ₀，就得到按 θ₀ 的分布

分母 4π 是常数，分子却带一个 sinθ₀，所以「相同的 θ₀ 宽度」并不等于「相同的概率」。这一点值得单独算一遍。

球面上 θ₀ 附近的一圈窄带有多大？为什么改用 cosθ₀ 计数更省事？

在单位球上，极角 θ₀ 处那条纬圈的半径是 sinθ₀，周长就是 2π sinθ₀；沿经线方向再走 dθ₀，这一圈窄带的面积是 2π sinθ₀ dθ₀。除以球面总面积 4π，就是极角落进这条细带里的概率，(16.7) 就是这么来的。球面靠近极点的地方窄带更细，同样的角度宽度对应的面积更小。

手算一段：θ₀ 落在 0° 到 60° 的概率是 (1 − 1/2)/2 = 1/4，落在 60° 到 90° 的概率是 (1/2 − 0)/2 = 1/4。两段角宽度一个是 60°、一个是 30°，概率却相等，因为决定概率的是 cosθ₀ 区间的长度。

于是换一个变量：令 u = cosθ₀。θ₀ 从 0 增到 π 时，u 从 1 减到 −1，而 |du| = sinθ₀ dθ₀，所以 (16.7) 可以写成 dP = |du|/2，也就是 u 在 [−1, 1] 上均匀分布、密度恒为 1/2。写的时候用 |du|，别把 u 的减小当成负概率。

分成三块以上，为什么只剩一个上限？

两体分裂里一块的平动状态被另一块的动量完全锁定，所以速率和动能都是确定的。三块以上不再如此：动量守恒只要求所有末态动量之和为零，剩下的粒子之间有无数种分配方式。结论先说清楚：单个粒子的动能仍然有上限，但一般不再有确定值。

把质量为 m₁ 的那一块挑出来，其余所有碎片合起来看成一个「剩余系统」，总质量记 R = M − m₁。若 m₁ 的动量是 p，剩余系统的总动量必然等于 −p。释放出来的 ε 要在三处分配：m₁ 的平动动能、剩余系统整体平动的动能、以及剩余系统内部相对运动的动能。原书的写法是把后面两处一起算进剩余系统的内能 E′int，写成 T₁₀ = ((M − m₁)/M)(E_int − E₁int − E′int)，再指出 E′int 最小时 T₁₀ 最大、而那要求其余粒子速度相同。本页把这两处拆开，结论相同，取等条件更清楚：内部相对运动的那一份记作 K_rel，它永远不小于零；给定 p 之后，整体平动的那一份只能取 p²/(2R)。

设剩余粒子的质量为 mⱼ、速度为 wⱼ，它们的质心速度是 W = Σmⱼwⱼ/R；由动量守恒还有 R W = −p。把每个速度写成 wⱼ = W + (wⱼ − W)，代进剩余系统的动能表达式再展开：

交叉项等于 W·Σmⱼ(wⱼ − W) = 0，因为 Σmⱼ(wⱼ − W) = 0 正是「W 是质心速度」的另一种写法；剩下的一项是平方和，非负，只有每一项都为零时才取等号。所以「所有剩余粒子速度相同」是一条精确的取等条件，不是「速度差不多就可以近似成立」。

举个数：剩余两块质量都是 1，总动量固定为 −2。让它们同速取 −1，动能合计是 1；把它们改成 −1 + d 与 −1 − d，总动量仍然是 −2，动能却涨到 1 + d²。多出来的这份能量对平衡 m₁ 所需的动量一点忙都帮不上，纯粹是内部相对运动浪费掉的。

推导总览：这一节的结论是怎么一步步来的

把整节的链条按顺序排一遍，每一环都只用到了前面的结果和前两章的守恒律；需要复习时按这五步走就够。

一、选参考系。在分裂前物体静止的 C 系里，末态总动量为零，两块动量大小相等方向相反，记作 p₀；分裂能定义成 ε = E_int − E₁int − E₂int（16.1）。能量守恒给出 ε = p₀²/(2μ)（16.2），由此 p₀、两块的速度以及两块动能 T₁₀ = εm₂/M、T₂₀ = εm₁/M 全部确定，前提是 ε 大于零。

二、换回实验室系。每个速度加上同一个 V，末态总动量仍是 MV，末态总动能是 ½MV² + ε；两块的速度差不变，方向被 V 带偏，V 足够大时两块都朝前飞。

三、几何化。实验室速度满足 v² + V² − 2vV cosθ = v₀²（16.3），端点落在以 V 为心、v₀ 为半径的球面上；V 与 v₀ 的大小决定射线与球面有一个还是两个正速率交点，前向锥的边界是 sinθmax = v₀/V（16.4）；角度关系 (16.5) 与反向映射 (16.6) 随之给出，一支还是两支由 λ = V/v₀ 与 1 的大小关系决定。

四、补统计假设。C 系发射各向同性，等价于 u = cosθ₀ 在 [−1, 1] 上均匀（16.7）；实验室动能是 u 的一次函数，所以 T 在 T_min 与 T_max 之间均匀分布（16.8）；换到按角的分布时，不是一一对应的部分要把两支的贡献相加。

五、多体分裂。剩余系统可以储存内部相对运动的动能 K_rel，原先的确定值变成上界 (T₁₀)max = (M − m₁)ε/M（16.9），取等要求剩余粒子速度相同。

复习时可以用下面几个问题自测，它们分别落在不同的层次上：「相反」为什么说的是 C 系的动量，而不是实验室系的？为什么同一条实验室射线上可能有两个正速率，什么时候只剩一个？各向同性为什么让 cosθ₀ 均匀，而不是让 θ₀ 均匀？三块以上为什么只剩下界？守恒律既然这么管用，为什么给不出分裂会不会发生、以多大概率发生？

与原书对照：正文的九条编号式子 (16.1) 到 (16.9) 都在这条链里，图 14 与两条脚注也各有落点。本页在主线之外补充的内容——弹簧分离模型、两条动能分配关系、负根与零根的排除、动能分布的归一化核对、u 到 z = u² 的概率折叠小例子、剩余系统动能分解，以及习题 3 的极值存在条件与临界速度——逐条列在下面的覆盖区，并写明各自的核验方式。

展开补充清单与核验方式

下面每一项都标【补充·自编】，只用到本节已有的守恒律与初等代数、求导；核验方式写在同一条里。


【补充·自编】两块用压缩弹簧连在一起的分离模型：只用来把「内部能量怎么变成平动动能」讲具体，它不是真实的微观分裂机制，也不进入任何推导。核验：它只提供情景，不产生结论。


【补充·自编】T₁₀ = εm₂/M、T₂₀ = εm₁/M 以及两者之比 m₂/m₁：由 (16.2) 直接推出。核验：取 m₁ = 1、m₂ = 3、ε = 4，得 μ = 3/4、p₀² = 6，两块动能 3 与 1，和为 4，与「两块动量相等」相容。


【补充·自编】实验室系两块动能之和等于 ½MV² + ε：由 C 系总动量为零推出。核验：取 m₁ = m₂ = 1、w 为 ±1、V = 2，C 系动能合计 1，实验室动能合计 5，多出的 4 正好是 ½MV²。


【补充·自编】负速率根与零速率根的排除：直接来自 (16.3) 的解析特例。核验：V = 2、v₀ = 1、θ = 0 给出 3 与 1 两个正根；V = v₀ 时方程化成 v(v − 2V cosθ) = 0，其中一根为零，该状态没有方向。


【补充·自编】动能分布的归一化与两种退化：区间宽度 2mᵢv₀V 乘密度 1/(2mᵢv₀V) 等于 1；V = 0 与 v₀ = 0 时分布退化成一个确定值，含 1/V 的密度式不再适用。核验：解析计算加区间宽度核对。


【补充·自编】u 到 z = u² 的概率折叠小例子：说明新旧变量不是一一对应时两支贡献相加。核验：解析求导得 z 的密度 1/(2√z)，再用积分 ∫₀¹ dz/(2√z) = 1 核对总概率。


【补充·自编】剩余系统动能分解与取等条件：把每个速度写成质心速度加内部偏移后展开，交叉项为零，剩下的是非负平方和。核验：平方和恒等式，并附两块质量都是 1、总动量 −2 的数值例子（同速时 1，改成 −1 ± d 后为 1 + d²）。


【补充·自编】习题 3 的极值存在条件、临界速度与端点：|c*| 不大于 1 等价于 (V² − a²)(V² − b²) 不小于零；V = a 与 V = b 时候选值落到端点上，而该端点有一块速度为零。核验：展开 (V² − ab)² − V²(b − a)² 得 (V² − a²)(V² − b²)；再用 a = b = 1、V = 1、θ₀ = 90° 得两块速度 (1, 1) 与 (1, −1)，夹角 π/2。
